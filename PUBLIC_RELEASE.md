# Source publication boundary

This source preview predates the planned Strata2.1 refresh. The private source
commit and per-file source hashes are in PUBLIC_SOURCE_MANIFEST.json.
Public history starts at this reviewed export. Full private history is retained.
Model weights, live stores/credentials, request journals, inherited benchmark
records and raw/large measurement archives are not part of this source release.
The manifest lists omitted paths. Source/tests/reference equations are unchanged;
README and release notes describe the packaging boundary. Nothing is published
to Niko1221/Strata by this release.

The tested candidate server is780e824a. The fleet service remains source4b1f8fda
on8099 after its completed trial; publishing source does not deploy a new server.
The separate input-projection branch is CPU-only and not GPU-qualified.
COW G0 has51/51 evidence. Complete G1-G5, broad controller/layout and sustained
pressure/soak/sanitizer qualification remain open. Repeated measurements in older
files retain their original source/profile scope; they do not certify this export.

The client, server and native executable must be treated as distinct identities.
An immutable history can survive checkpoint eviction, but later continuation may
need explicitly reported recomputation. Same-profile/schedule restart results do
not establish arbitrary batch-arrangement equivalence. Greedy and tested sampler
fixtures do not prove every controller/image combination.
