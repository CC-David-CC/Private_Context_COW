# Context COW v0.1.1 release candidate

The candidate adds an explicitly caller-managed write-integrity experiment and
reuse of access permissions on already private, writable pages. It preserves
the guarded v0.1.0 path, history/controller format, batched prefill, oracle and
consumed-token publication boundary. The ordinary engine and native production
source are unchanged; the new builder links an isolated replacement object only
into the experimental branching executable.

## Measured starting point

The first no-scan four-lane run passed 516 full-logit comparisons with zero
error. Resident A preparation fell from 0.190777 to 0.012161 seconds over 128
outputs; native TPS rose from 47.37 to 50.50. Reusing writable access reduced
preparation further to 0.004876 seconds and measured 50.83 TPS. RAM measured
51.63 before this change and 51.76 with writable-access reuse. These are single
serial samples; the tiny RAM/TPS difference is not a statistical speed claim.

## Evidence required for this bounded candidate

| Work | Required evidence |
|---|---|
| Repeat v0.1.0 | Same guarded binary hash, 8K + 512 + 128 fixture, four lanes, exact full-vocabulary logits and unchanged parent/checkpoint bytes |
| Repeat candidate | Same hardware/resources and fixture, explicit caller-managed profile, four lanes and the same independent oracle/audits |
| Native controls | v0.1.0 page, batch, preparation, session, integrity and lifecycle tests; independent SHA checks |
| Candidate fixture | Actual CUDA ownership/range checks, parent isolation and zero per-write hash work across four KV formats |
| Changed promise | Deliberate shared-page corruption rejected by the guard, accepted before write by the caller-managed variant, and visible to an independent byte audit |
| Sanitizer | Candidate native fixture under real CUDA memcheck, no reported errors |
| Reference/controller | G0, reference demo, four reference mutants, controller-copy and profile-input regressions |
| Publication | Raw passing/failing reports, binary/build/model fingerprints, paired comparison figure, reproducible commands and explicit policy limits |

The first caller-managed fixtures passed 214 checks for both variants; the
guarded counterpart produced the expected 16 policy-difference failures, and
candidate memcheck reported zero errors. Both initial model runs passed 516
exact comparisons each. The first baseline rerun rejected a stale CMake
fingerprint before loading the model; a freshly bound unqualified profile was
created without changing binaries, fixtures or numerical assertions. That
failure is retained alongside the repeated measurements.

## Completed bounded candidate campaign

The fresh guarded baseline and candidate reruns both passed all four lanes,
516 exact comparisons each, maximum error 0.0. Native COW gains were 6.63%
(resident A), 6.38% (resident B) and 6.54% (disk B). RAM changed 0.47%, a small
observed difference. Resident A preparation dropped 183.75 -> 4.76 ms over 128
outputs. Copy counters, tokens and parent/checkpoint fingerprints matched.

The six native regressions, three SHA unittest methods, four controller methods,
four profile-input methods, G0, reference demo and reference mutants passed.
Candidate memcheck had zero reported errors. The stale-profile failure and both
initial/repeated campaigns are retained. The package is ready as a bounded
experimental v0.1.1 release candidate; full gate/portability qualification is
outside the completed campaign. See [the measured comparison](EXTERNAL_WRITE_INTEGRITY.md).

## Release boundary

The experiment transfers a promise: the caller must prevent other aliases or
writers from modifying sealed physical pages between validation and use.
Ordered host metadata, range and ownership/COW checks remain. Restore and
capture still hash state, but there is no byte scan before each write. This
mode cannot claim the original automatic corruption-detection guarantee.

The candidate remains experimental. Arbitrary batched splits, ordinary serving
repeatability, native Windows locking, HIP/SYCL and the full certification/soak
matrix remain open. A v0.1.1 package does not imply G1–G5 PASS. Keep the v0.1.0
tag immutable; report the repeated baseline separately rather than overwriting
its original measurements. Expand context sizes after the bounded comparison
is complete, not by extrapolating these timing samples into a 128K claim.
