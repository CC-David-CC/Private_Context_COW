# Context COW v0.1.2-rc1

This candidate incorporates the shared LaTeX math core from Strata PR #1829
and both locally bundled viewers from PR #1830 (KaTeX) and #1832 (MathJax).
It builds on v0.1.1-rc1 and provides a persisted viewer selector, lazy loading
and cancellation-safe viewer switching. Rendering is off by default; source
remains authoritative for copying, export, history and model requests.

Read [the usage, provenance and test report](../WEB_MATH.md).

| Validation | Executed result |
|---|---|
| KaTeX shared acceptance | Chromium, Firefox, WebKit: PASS |
| MathJax shared acceptance | Chromium, Firefox, WebKit: PASS |
| Shared equation corpus | 60 observations: expected renders/rejections |
| Dual-viewer switching | 3 suites / 75 named check observations: PASS |
| Server/security/frontend regressions | 50 methods: PASS; zero failures/errors/skips |
| Native engine and branching-store source diff | No changes relative to v0.1.1-rc1 |

Browser tests use the real renderers with a mock inference service; no new model
measurements or formal gate qualification are claimed. The v0.1.1 numerical,
sharing and speed evidence keeps its original scope. Arbitrary prefill splits,
ordinary serving repeatability, portability and full certification remain open.

The source PR heads used were:

- #1829: `4010abec43d4b2307ff0c8cac3604af2868bf9fe`.
- #1830: `e1fefc11580caadde7622c0d1ce77c5437abf563`.
- #1832: `2dd2ddfa1f416f5f453c436e2896271b6c5ff43d`.

The core patch is preserved as a cherry-pick of `56063f31`; engine code is
adapted only to register both viewers instead of overwriting one global adapter.
The integration also prevents an old renderer's in-flight result from hydrating
after selection changes. Third-party licenses and pinned provenance are bundled.
