# Consumed-boundary pause: model-layer CPU milestone

This adds an optional transient paused callback to run_state_request and its plain sampled wrapper. It is a work bound: after a selected token is actually consumed, stop admitting more tokens, capture the complete frontier/controller, and publish a normal partial snapshot. An initial pause still consumes one token so the existing generation response remains valid. EOS/stopping remains authoritative. Existing destructive cancellation still raises and discards uncommitted work; pause does not turn cancellation into a success. Parent snapshots remain immutable. No history/checkpoint format, RNG algorithm, grammar meaning, hash equation, numerical tolerance or default thinking budget changes.
